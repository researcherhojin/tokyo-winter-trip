## 추가 원문 직접 검색 검증

앞선 Openverse 질의를 반복하지 않고 Flickr 검색 원문과 검색 결과의 공개 사진 모델을 직접 대조했습니다. 결과는 `src/data/foodPhotoSourceAudit.json`에 검색 URL·결과 수·실제로 받은 사진 기록 수·제외 사유로 저장했습니다. 이번 회차 신규 채택은 **0장**입니다. 앞서 확보한 웨스트·나나야·기오이 세이도 사진을 이번 성과로 중복 집계하지 않습니다.

- 하토야의 영어 검색 4개 후보는 원문을 각각 열어 촬영일을 대조했습니다. 2009~2010년의 옛 다방 사진으로 2023년 문을 연 八十八浅草와 일치하지 않습니다. 1개가 CC 비상업적 조건이어도 점포 불일치가 먼저이므로 채택하지 않았습니다.
- 베타나기 일본어 2개 후보는 식당으로 확인되지 않았고 모든 권리 보유입니다. 영문 후보도 동일 식당 근거가 없습니다.
- 에노시마·Treasure 검색은 57개 결과를 보고했지만, 응답으로 실제 받은 사진 기록만 검토했습니다. 신사의 보물전·사찰을 카페 사진으로 연결하지 않았습니다.
- 400℃·시나가와 질의는 일반 숫자·피자·도쿄 결과를 함께 반환합니다. 전체 518개를 검토했다는 주장은 하지 않으며, 실제 응답 범위에서 해당 점포로 확인되는 사진은 확보하지 못했습니다.
- かめ幸·たばねのし 정확 상호 검색은 결과가 없었고, 花ぞむかしの의 결과는 시구를 찍은 사진입니다. 음식점 사진으로 대체하지 않았습니다.
- 일반 아사쿠사·말차 검색도 확장했지만 다른 점포·이전 시기의 식품·모든 권리 보유 사진을 해당 점포에 배정하지 않았습니다.

공식 사이트의 사진이 열람 가능하다는 사실과 앱 안에 복제할 수 있다는 조건은 구분합니다. 이번 조사에서 해당 식당·카페가 공개 재사용을 허용한 공식 사진 조건은 확인하지 못했습니다. 다른 매장·일반 음식·AI 이미지를 추가하지 않았습니다. 정확한 점포 사진의 사용 허가를 받거나 직접 촬영한 사진이 제공되면 기존 항목 ID에 바로 연결할 수 있습니다.

## 정확한 공식 사진 원본과 기존 연결 재감사

`src/data/officialFoodPhotoCandidates.json`은 실제 재사용 사진 manifest가 아닌 **허가 확인용 후보 자료**입니다. 7곳의 정확한 원문·이미지 URL·게시 크레딧·이용조건·연락 경로와 확인일을 저장했습니다. `displayAllowed:false`, `downloaded:false`로 구분하며 사진 본문을 로컬 아카이브에 복제하지 않았습니다. 외부 사진 링크를 `img src`로 자동 사용하도록 연결하지 않습니다.

차료 하나는 [茶寮花ぞむかしの 공식 LINE](https://page.line.me/501puybv)을 새로 확인했습니다. 주소 浅草1-18-9, [직화 치즈케이크 개별 상품](https://page.line.me/501puybv/showcase/1188990956819705/item/1189122149606527), 11:00–18:00·수요일 휴무를 확인했습니다. 이로써 기존에 공식 출처를 찾지 못한 상태에서 진전이 있으나 사진 복제권까지 취득한 것은 아닙니다. 긴자 かめ幸 역시 공식 LINE의 오뎅 개별 상품 이미지 원본을 특정했습니다.

시나가와 피자점은 해당 점포 TableCheck 페이지의 original 이미지 URL을 특정했습니다. [TableCheck 콘텐츠 약관](https://www.tablecheck.com/en/policy/content/)은 서비스·지정 파트너의 이용권과 일반 방문자의 재사용을 구분하며 무단 복제를 허용하지 않습니다. 하토야는 다른 지점의 브랜드 사진 대신 매장 제공 크레딧이 명시된 아사쿠사점 소개 원문으로 좁혔습니다. 타바네노시의 개별 메뉴 이미지, 베타나기·트레저 카페의 공식 외관 URL도 식별했으나 모두 공개 복제 허가 미확인입니다.

기존 나나야 연결은 엄격한 점포 일치 기준에서 제외를 권고합니다. [운영사의 2016년 개점 발표](https://www.atpress.ne.jp/news/109461)는 아오야마점이 2016-08-19 문을 열었다고 안내합니다. 2015년 제라토 사진은 이 점포에서 촬영됐을 수 없습니다. 2022년 초콜릿 사진은 브랜드만 식별되고 지점은 확인되지 않았습니다. 두 사진의 CC 라이선스 자체와 별개로 **점포 사진 연결에는 부적합**합니다. 반면 웨스트의 2018년 팬케이크는 원문이 해당 지점을 명시하며 [공식 지점 소개](https://www.ginza-west.com/hpgen/HPB/categories/17547.html)에도 핫케이크가 소개되므로 유지할 수 있습니다. 수플레라는 이름을 붙이지 않습니다. 나나야2장은 실제 manifest·UI 연결·공개 자산에서 제외했고 웨스트 팬케이크는 유지했습니다.

관광사진 라이브러리도 별도로 검토했습니다. [GO TOKYO 사진 이용조건](https://www.gotokyo.org/photo/en/agent/photo_terms.html)은 도쿄 관광 홍보 목적의 무료 이용을 제공하지만 신청·심사 승인 후 다운로드 URL을 주며 직접 이미지 링크는 금지합니다. [후지사와시 관광협회 이용조건](https://photo.fujisawa-kanko.jp/termsofservice/) 역시 사용자·목적을 명시한 신청과 크레딧을 요구합니다. 두 서비스가 무료라는 점을 사전 절차 없이 복제할 수 있다는 허가로 해석하지 않았습니다. 외부 신청이나 타인에게 연락하는 동작은 수행하지 않았습니다.
