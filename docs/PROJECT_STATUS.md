## 6회차·사진 재검수·배포·공개 · 2026-10-18

- **사진 재검수:** 사용자 지적(「약사진에 건물 사진 이게 맞습니까?」)으로 제조사 건물·매장 외관·거리 사진 13장을 모두 뺐습니다. 참고 사진은 카드와 같은 종류(음식·상품)만 쓰도록 [사진 검수 스킬](../.claude/skills/tokyo-photo-vetting/SKILL.md)과 접촉 시트 도구(`scripts/contact-sheet.mjs`)를 만들었습니다. 사용자 승인 후 12곳 반영(웨스트 슈크림·유하임 바움쿠헨은 브랜드 실제 음식, 10곳은 비슷한 참고 사진). 79개 카드의 첫 사진을 모아 검수해 오이와케 당고의 첫 사진을 가게 건물에서 당고·차 세트로 바꿨습니다.
- **약 7곳:** 자유 라이선스 실제 제품 사진이 없고 각 사 약관상 공식 사진을 게재할 수 없어, 사용자 선택에 따라 이름 타일과 「공식 사진」 버튼을 유지합니다. 여행 중 직접 찍은 사진으로 채울 예정입니다.
- **공개:** Cloudflare Pages(https://tokyo-winter-trip.pages.dev)에 지도 키를 사이트 제한 후 포함해 배포, 공개 저장소 https://github.com/researcherhojin/tokyo-winter-trip 생성(MIT). README는 화면 캡처와 짧은 표로 간결하게, 자세한 그림은 [ARCHITECTURE](ARCHITECTURE.md), 과정은 [만든 과정](PROMPTS.md). 화면 상단 Notion 옆 GitHub 아이콘, 휴대폰은 테마 탐색 하단 안내에 링크.
- **Notion:** 여행 본문·개발 기록 페이지가 Claude Notion 연결에 공유되지 않아 조회 404. 사용자가 페이지 「연결」에 Claude를 추가하면 읽기부터 확인합니다(원본 일정·예약·첨부는 수정하지 않음).

## 5회차·카드 간결화·탭·사진 · 2026-10-18

- **카드:** 사진 아래 참고 주석 줄, 관계 칩(작품 등장 등), 여행일 휴무 칩, 작품 영상 비교를 사용자 요청으로 뺐습니다. 운영시간·휴무는 「 · 」·「 / 」 단위 줄로, 괄호 세부와 주소·입장·여행 중 휴무·출처·공식 자료는 「방문 정보·출처」 모달로 옮겼습니다. 저장 버튼은 아이콘(보이는 원 34px, 누를 영역 44px). 넓은 화면은 3열(콘텐츠 940px 이상)·4열(1400px 이상), 본문 최대 1760px.
- **사진:** 하마마쓰초 데크·에비스 바카라·아자부다이 전망(가로 사진), 시바공원 크리스마스 마켓(같은 회장 2019년 사진, 연도 표시), 이케부쿠로 PARCO·마쓰자카야 우에노(판매처 참고)·요요기 건널목(비슷한 참고)을 추가했습니다. 메이지 신궁 사진 2장은 카드가 「메이지진구 뮤지엄」이라 넣었다가 뺐습니다. 공식·보도자료 이미지는 22개 항목 약관을 확인했으나 모두 사적 이용·보도 한정 또는 허가 필요였습니다.
- **테마 순서:** 묶음 이름이 테마 이름과 겹치던 것(캐릭터·굿즈 안의 캐릭터·굿즈)을 정리하고, 기본 선택을 목록 첫 테마로 맞췄습니다. 철길 테마 커버와 머리 높이(카드 시작 1440 231px)도 정리했습니다.
- **준비 체크·여행 지도:** 준비 체크를 3단계 탭으로, 일정 카드 간격·타임라인·출처 위치를 정리했습니다. 휴대폰 지도는 덮개 요소를 측정해 보이는 영역에 마커를 맞춥니다.

- **카드:** 세로 사진이 쉴 때 32–49%만 보이고 마우스를 올리면 0.32–0.49배로 줄던 문제를 고쳤습니다. 모든 사진을 자르지 않습니다. 설계는 [디자인 리뷰](DESIGN_REVIEW.md#카드-사진모션-재작업--2026-10-18)와 [Airbnb 측정](DESIGN_REFERENCES.md#테마-카드-사진--airbnb-검색-결과-카드--2026-10-18)에 있습니다.
- **방문 가이드:** 날짜별 감사로 경로 3건(츠키지 오에도선 1분, 해리포터 도초마에 환승, 게이오 직통)을 고쳤습니다. 포케파크 운영시간 변경 보도, 토리코로루 화요일 휴무, 일몰 16:28, 일루미네이션 기간, 예약을 전제한 문구도 바로잡았습니다.
- **지점별 사실:** 카페 사후(茶楓) 표기·위치, LOOPS 근거 없는 「혼 스피커」, 후나보리 연말 휴관, MoN 12월 휴관일 등을 공식 지점 페이지로 고쳤습니다. 다른 지점 정보가 섞인 카드는 장소·건축·캐릭터 테마에서 발견되지 않았습니다. 식당·카페는 별도 감사 결과를 반영합니다.
- **카드·화면 통일:** 카드 본문(지역·휴무 칩·출처 줄), 사이드바 224px, 일정 패널 여백, 준비 체크 레이아웃을 테마와 통일했습니다. 상세는 [디자인 리뷰](DESIGN_REVIEW.md#카드-본문테마-사이드바일정-패널준비-체크-통일--2026-10-18). 상품 14종은 공식 제품명으로 갱신(츠메큐어→チュメキュア, 구내염 패치 A는 2023년 회수)했습니다.
- **12월 도쿄에서 할 일:** 여행 기간에 열리는 크리스마스 마켓·일루미네이션 8곳을 새 테마로 추가했습니다(시바공원 크리스마스 마켓, 스카이트리·마루노우치·미드타운·롯폰기 힐스·에비스·신바시·아자부다이). 2026년 회장이 히비야에서 시바공원으로 바뀐 점, 스카이트리 특별 라이팅이 12/12에는 없고 12/14에는 있는 점을 반영했습니다. 신바시·아자부다이는 2026년 미발표라 「방문 후보」로만 표시합니다. 준비 체크에는 11/1 면세 제도 변경(출국 시 환급), Safety tips 앱·JNTO 핫라인을 추가해 17개가 됐습니다. 해외판 갤럭시의 Welcome Suica Mobile은 2027년 상반기 예정이라 실물 Welcome Suica로 안내합니다. 제외한 후보: 카렛타 시오도메(2020년 이후 개최 근거 없음), 하고이타이치(12/17–19), 아메요코 연말 시장(12월 하순).
