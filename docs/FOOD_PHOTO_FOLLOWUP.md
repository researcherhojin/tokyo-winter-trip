# 식당·디저트 사진 추가 조사

> 현재 상태는 [사진 아카이브](PHOTO_ARCHIVE.md)를 기준으로 합니다. 아래는 조사 시점의 기록이며 연결 제안·확보 수가 현재 공개 상태를 뜻하지 않습니다. 2026-10-18 재감사에서 부적합 사진 18개를 공개 자산에서 제외했고, 사진 64장·대표 연결44/78개·미확보 34개로 갱신했습니다.

확인일: 2026-10-18. Commons와 공개 CC 인덱스 Openverse에서 일본어 상호·영어 상호로 검색한 뒤, 채택 사진의 Flickr 원문 HTML에 기재된 라이선스와 사진을 직접 대조했습니다. 운영사 웹사이트의 사진은 명시적 재사용 허가를 확인하지 못했으므로 내려받지 않았습니다. 검색에서 사진을 찾지 못했다는 뜻이지, 해당 장소의 사진이 존재하지 않는다는 뜻은 아닙니다.

원문 링크 열기는 가능하지만, 이 링크의 사진을 앱 안에 자동 복제하는 구현은 하지 않았습니다. 허가를 받은 원본이나 직접 촬영한 사진이 생기면 해당 항목의 사진 자료로 추가할 수 있습니다. 유하임·오이와케·토리코로루·라드리오·본디는 기존 `extraItemPhotos.json`·`extraPlacePhotos.json` 사진을 재사용하며 중복 다운로드하지 않았습니다.
