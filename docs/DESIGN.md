# Tokyo travel journal 디자인 시스템

Tripsy의 지도+시트 구조와 Wanderlog의 일정·지도 연결 방식을 여행 당일에 맞춰 적용합니다. 기존 큰 일차 사진과 설명을 먼저 보여주던 구성을, 지도를 중심으로 날짜·방문 행·장소 사진을 연결하는 도구로 바꿉니다.

- 색: paper #ffffff, canvas #f3f5f7, ink #20272b, secondary #576166, line #e1e6e8, vermilion #b73828. 지도 핀과 선택 상태는 도쿄의 주홍색 한 계열로 통일합니다.
- 글자: Avenir Next 브랜드, 시스템 한글 고딕 본문16px·행간1.65, 시간18px, 장소18px, 일차제목24px. 브랜드·숫자·한글의 역할을 구분하고 외부 폰트 요청은 추가하지 않습니다.
- PC: 전체 지도를 배경 작업 영역으로 두고 왼쪽의 날짜 탐색과 떠 있는 일정 패널을 연결합니다. 지도 범위는 패널에 가리지 않는 영역으로 계산합니다.
- 모바일: 상단 날짜, 지도, 하단 일정 시트를 동시에 유지합니다. 지도 집중·일정 펼치기 두 높이를 제공하고 모든 조작은 버튼으로도 가능합니다.
- 일정: 시간→장소→예약 상태 순서, 해당 장소의 작은 사진, 바로 누르는 길찾기. 긴 원문 메모와 환승은 펼쳐 확인하며 중요한 미확정 상태는 행에 남깁니다.
- 사진: 실제 장소 식별에 사용합니다. 첫 방문 행에만 표시하고 반복 방문에서는 생략합니다. 저작자·라이선스·주변 전경 여부를 표시합니다.

PC 개념: 헤더 / 전체 지도 + [날짜 탐색, 일정 패널] / 선택 장소 정보.
모바일 개념: 헤더 / 날짜 / 지도 / 확장 가능한 일정 시트.

이 앱은 소개 페이지가 아니라 여행 중 사용하는 지도 도구입니다. 큰 사진 히어로와 동일한 배지·설명 카드 반복을 제거하고 한 개의 작업 패널에 정보의 위계를 둡니다. 사진이나 UI 장식 때문에 시간표가 첫 화면 아래로 밀리지 않는지 실제 화면에서 확인합니다.

## 2026-10-18 화면 간 일관성 개선

Tripsy와 Wanderlog의 공식 공개 화면을 다시 검토했습니다. 지도 작업 영역은 유지하고, 테마·준비 화면을 동일한 제목 크기·콘텐츠 폭·간격·표면·선택 색으로 연결합니다. 테마는 PC에서 카테고리 레일과 검색 결과, 모바일에서 가로 카테고리와 단일 열 목록을 사용합니다. 준비 화면은 체크리스트를 주 작업으로 두고 환율·Suica를 보조 영역으로 배치합니다. 환율이 첫머리를 차지하던 문제를 정보 우선순위 변경으로 해결합니다.

전체 재설계를 다시 했다고 주장하지 않습니다. 이번 범위는 세 화면 사이의 탐색 체계와 정보 위계 통일, 공식 근거가 있는 장소별 안내를 읽기 좋은 상세 구조로 제공하는 것입니다. 장소 상세는 개요→지도 동작→운영·예약→추천 방문 순서→접근·예산→주의·출처 순서이며, 추천 순서는 확정 일정과 구분합니다. 본문16px, 조작44px, 단일 주홍색 선택 상태를 공통으로 유지합니다.
