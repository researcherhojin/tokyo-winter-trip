# 개별 테마 사진 보강 기록

> 현재 상태는 [사진 아카이브](PHOTO_ARCHIVE.md)를 기준으로 합니다. 아래는 조사 시점의 기록이며 연결 제안·확보 수가 현재 공개 상태를 뜻하지 않습니다. 2026-10-18 재감사에서 부적합 사진 18개를 공개 자산에서 제외했고, 사진 64장·대표 연결44/78개·미확보 34개로 갱신했습니다.

2026-10-18 편의점 7·약국 7·식당 2·카페와 디저트 8 항목을 조사했습니다. 재사용 조건이 확인된 실제 사진 4장을 3개 항목에 추가했고, `src/data/extraItemPhotos.json`에서 항목과 사진을 연결합니다.

- 토리코로루 본점: Kentin, 2014년 실제 본점 외관. 세로 구도이므로 창과 붉은 차양·입구가 보이도록 표시를 확인해야 합니다.
- 오이와케 당고 혼포: 江戸村のとくぞう, 2010년 실제 매장 입구와 해당 점포의 진열 화과자. 진열 사진은 당고 꼬치가 아니라고 명시했습니다. 가로 구도입니다.
- 유하임: 毒島みるく, 2019년 실제 바움쿠헨. 우에노점의 외관이나 즉석 커팅 사진은 아니며 캡션에 구분했습니다. 가로 구도입니다.

네 파일 모두 `view_image`로 직접 확인했습니다. 다운로드된 원본을 보관하며 저작자·라이선스·원본 링크는 [추가 사진 이용 조건](../public/photos/ITEM-LICENSE.md)에 기록했습니다. 세 장은 CC BY-SA 4.0이며 유하임 사진은 CC0입니다.

나머지 21개 항목은 `unavailable`에 이유와 확인일, 사진이 확인된 경우 공식 원문 링크를 남겼습니다. 대부분 공식 상품·매장 사진의 재사용 허가를 확인하지 못했습니다. 메뉴명이 없는 맥도날드 버거와 제품명이 불명확한 츠메큐어는 특정 상품 사진으로 대체하지 않았습니다. 약국·편의점의 일반 대표 사진을 개별 제품마다 반복해서 붙이지 않았습니다.

Wikimedia Commons 공개 API 조회가 429로 실패해 공개 파일 설명 페이지와 원본 HTML로 저작자·라이선스·사진 주소를 확인했습니다. 검색 결과 중 관련 없는 나나야 신화 자료, 다른 나라의 웨스트 매장, 식물 화분으로 사용한 오래된 비오페르민 병, 역사 광고는 채택하지 않았습니다. 제품·장소의 동일성이 확인되지 않은 사진과 단순 브랜드 로고는 개별 실사진 보강으로 세지 않습니다.

라드리오와 본디의 실제 음식 사진을 각각 추가해 현재 총 6장·5개 항목에 연결했습니다. 라드리오는 2023-10-20 촬영·Araisyohei·CC BY 4.0, 본디 진보초 본점은 2024-05-11 촬영·ウィ貴公子·CC BY-SA 4.0입니다. 두 사진 모두 가로형 960px 공개 축소본을 내려받고 view_image로 직접 확인했습니다. 과거 음식 사진이며 현재 제공 메뉴·가격을 확정하는 자료로 사용하지 않습니다.
