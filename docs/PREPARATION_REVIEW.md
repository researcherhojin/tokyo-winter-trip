# 준비 체크 사용성 검토

2026-10-18. 장소 후보 요요기를 뺀 15개 준비 항목과 `tokyo-2026-checklist-v1` 로컬 저장 키를 유지했다. API 조회·검증 실패 시 대체 안내는 기존 `usePreparationCatalog`가 담당한다. 개인 체크 상태는 서버로 전송하지 않는다.

사용자가 큰 요약 카드와 반복 문구를 다시 지적하여 목록 중심으로 재구성했다. 번호가 붙은 세 칸 요약과 반복되는 '확인 전·상세 안내를 열어…' 문구를 제거했다. 제목·완료 수·얇은 진행률 다음에 필터와 실제 체크 목록이 바로 나온다. 항목별 보조문은 티켓 입장 창, 예약 기한, 귀국 도착 목표 등 구체적인 확인 내용이며 상세 버튼을 열면 기존 실행 안내와 근거를 읽는다.

해리포터·숙소·이전 숙소 취소 기한 바로가기는PC 오른쪽280px 보조 영역에 둔다. 모바일에서는 체크 목록 다음에 나온다. 동일한 흰색·회색·먹색·붉은 선택색과 한국어 시스템 서체를 사용하고 강조색·장식 번호·추가 아이콘을 늘리지 않았다. Tripsy 일정 밀도 레퍼런스와 frontend-design 스킬의 반복 카드·무의미한 번호·장식용 안내 라벨 지양 기준을 검토했다. 이는 사용자의 미적 선호에 대한 최종 승인을 의미하지 않는다.

체크는 개인 확인 기록이며 예약·결제 확정이나 취소 처리를 수행하지 않는다고 한 번 안내한다. 전체·미완료 필터와 그룹별 완료 수, 기기 저장·백업을 유지한다. 참석자 이름은 표시하지 않는다. Suica 안내를 참고 환율보다 먼저 배치하고 환율은 접어둔다.

백업은 기존 boolean 객체 형식이다. 복원 시 최대 1MB, 객체 형태, boolean 값, 현재 목록의 ID 포함 여부를 확인한다. 알려진 항목만 기존 상태에 병합하므로 부분 백업은 없는 항목을 지우지 않는다. 잘못된 파일은 현재 상태를 유지한다. 읽기·저장 제한과 잘못된 저장 형식도 화면 메시지로 알린다. 원본 읽기 실패 직후 저장 자료를 자동 덮어쓰지 않는다. 사용자가 새 체크를 변경하면 현재 체크로 저장한다.

검증 시나리오:

1. 기존 저장 값이 있으면 새로고침 후 동일하게 복원되고, 그룹·전체 완료 수가 일치하는지 확인한다.
2. 미완료 필터에서 항목을 체크하면 행이 사라지고 남은 수가 줄어든다. 모두 완료하면 빈 상태와 전체 보기 버튼이 나타난다.
3. 미완료 필터에서 이미 완료한 우선 항목을 누르면 전체 필터로 바뀌고 해당 체크에 초점이 간다.
4. 각 확인 방법을 열어 공식·공유 기록 링크와 조건을 확인한다. 체크·링크·접기는 키보드로 사용할 수 있어야 한다.
5. 백업 후 부분 boolean 객체를 불러오면 해당 ID만 바뀐다. 배열·문자열 값·알 수 없는 ID만 포함된 파일은 오류 메시지와 함께 원래 상태를 유지한다.
6. 저장이 차단된 환경에서 이번 화면 체크는 유지되고 백업 안내가 보인다. API 오류는 체크 상태를 초기화하지 않는다.
7. 1440·768·390·320px에서 체크·필터·링크·접기 터치 영역 44px 이상, 가로 넘침·긴 안내 가독성을 확인한다.

구현 검증: TypeScript·cSpell 및 62개 자동 테스트 통과. 실제 Chrome에서 위 필터·초점 이동·새로고침·잘못된 백업·부분 병합·다운로드·완료 빈 상태를 확인했다. 1440·768·390·320px 가로 넘침 0건, 검사한 조작 영역44px 미만 0건, 페이지 예외 0건이다. 결과는 output/playwright/design-audit.json의 preparation이며 PC·모바일 캡처를 직접 검토했다. 예약 서비스 로그인·결제·취소·외부 배포는 실행하지 않았다.

요요기 장소 소개·주변 위치 검색과 방문 체크는 사용자 요청으로 준비 페이지에서 제거했다. 철길 테마의 장소 후보는 유지한다. 기존 저장 객체에 남은 요요기 체크 값은 다른 체크를 지우지 않도록 보존하며 현재 목록 집계에서는 제외한다.

## 실제 준비 순서

항목 15개의ID·기기 저장 키를 유지하고 아래3단계로 카탈로그 순서를 변경했다. 다른 항목의 체크 값을 옮기거나 초기화하지 않는다.

- 먼저 확정할 예약 6개: 여권·항공권 → 해리포터10시 예매·결제 → 신바시 숙소 확정 → 새 숙소 확정 후 이전 예약 취소·환불 → 스카이트리 예약 → 저녁 장소·시간.
- 교통·입장 준비 5개: 포케파크 권종·입장 창·QR → 공항 이동편 → Suica 지원 기기 → 등록·충전 → 익스프레스 설정.
- 출발 전 최종 확인 4개: 공원 운영·곤돌라 → 스타워즈 입장·체험 공지 → 방문 매장 영업 → 통신·QR·여권·짐 챙기기.

여권 확인은 뒤늦은 짐 챙기기와 구분해 첫 항목에서 영문명·유효기간·항공권 이름을 대조한다. 이전 숙소 취소는 새 숙소 확정 확인 다음에 두고 상세에도 선행 조건을 명시했다. 일정 합의·티켓 근거·계획 시간과 실제 예약 확정은 구분한다.
