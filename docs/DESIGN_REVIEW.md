# 현재 UI 자체 디자인 리뷰

현재 화면은 아래 ‘테마 카드 밀도·사진 모션 조정’과 [프로젝트 현황](PROJECT_STATUS.md)을 최종 기준으로 합니다. 앞부분은 이전 변경의 검토 이력입니다. 테마는 78개 후보이며 부적합 사진 18개와 삭제 요청한 장소 3개를 제거했습니다. 사진이 없는 후보도 동일한 카드 순서·사진 프레임 크기를 유지하고, 검증된 사진을 가진 테마에만 대표 사진을 표시합니다.

2026-10-17. [gstack design-review 원본](https://github.com/garrytan/gstack/blob/main/design-review/SKILL.md)의 시각 위계·타이포그래피·대비·상호작용·반응형 검토 관점을 참고했습니다. gstack 실행기와 자동 탐지 엔진은 설치·실행하지 않았습니다. 실제 Chrome을 Playwright CLI로 검토한 **자체 리뷰**입니다. 독립 모델 리뷰나 사용자 디자인 승인을 대신하지 않습니다.

이 화면의 목적은 여행 중 일정·지도·길찾기를 사용하는 것입니다. 랜딩 페이지처럼 사진·브랜드 표현만 강화해서 평가하지 않습니다.

## 지도·테마 화면 통일 · 2026-10-18

사용자 스크린샷에서 지도는 작은 도구 패널, 테마는 큰 문서 제목과 사이드바여서 같은 서비스의 탐색 화면으로 읽히지 않았습니다. 테마의 별도 페이지 헤더를 제거하고 지도와 동일한 왼쪽 패널 폭·패널 모서리·상단 구분선·짙은 선택 상태를 적용했습니다. 패널·글자 규칙은 기존 지도에서 가져오고 관련 CSS의 중복 정의를 정리했습니다.

테마는 선택·검색 패널과 장소 결과 패널로 나눴습니다. 도쿄타워 대표 사진을 표시하되 개별 촬영 후보 사진으로 오인하지 않도록 출처 펼침에 범위를 명시했습니다. 모바일은 작은 대표 썸네일과 가로 테마 선택으로 목록 진입을 단축했습니다. 카드의 전체 주소·긴 방문 설명은 펼쳐 보고, 후보·접근 미확인 표시와 공식 출처·길찾기·저장은 유지했습니다. 검증된 장소 사진이 없는 후보에 다른 장소 사진을 붙이지 않았습니다.

실제 Chrome에서 두 화면의 패널 폭440px·모서리18px·제목24px·선택색 rgb(32,39,43)이 일치함을 검사합니다. 화면의 사용 목적에 따라 지도 캔버스와 장소 결과 영역은 다릅니다. 전체 화면을 동일한 배치로 복제했다는 의미가 아닙니다.

캡처: output/playwright/themes-desktop.png, themes-mobile.png. PC·모바일 캡처를 직접 검토하고 모바일의 큰 대표 이미지를 작은 썸네일로 수정했습니다. 320·390·768·1440px 가로 넘침 없음, 기존 기능 및 API 대체 화면 검사 통과. 테스트 54개와 빌드·cSpell·키 검사도 통과했습니다. 자동 측정은 사용자의 미적 선호 승인을 대신하지 않습니다.


## 테마 대표·실제 조망 사진

테마 11개 모두 대표사진을 제공합니다. 아카바네바시 교차점, 시바3초메 편의점 외관 대조 후보, 아자부다이33층 조망은 각각 별도 사진으로 연결했습니다. 총 29개 로컬 사진을 사용합니다. 아카바네바시·아자부다이는 원문에 촬영 위치가 명시되며 시바 편의점은 외관 대조 근거와 정확한 발 위치 미확정을 캡션에 표시합니다. 남은 4개 타워 후보에는 위치·사용권을 함께 확인한 사진을 확보하지 못해 다른 장소 사진을 넣지 않았습니다.

사용자의 넓은 화면 캡처에서 사진이 목록을 밀어내는 문제를 확인하여 미리보기를 최대220px 높이로 크롭합니다. 대표사진은PC140px·모바일96px 높이입니다. 마우스 hover·키보드 focus에서는 같은 프레임 안에서 contain으로 전체 구도를 보이고, 클릭·터치는 원본 비율 모달을 엽니다. 사진 영역 크기는 상호작용 중 변하지 않습니다. 큰 화면의 카드 열 수는 사용 가능한 폭에 맞춰 늘립니다. 테마 대표사진은 특정 매장·제품 사진과 구분합니다. 사진·촬영 범위·저자·라이선스는 각 사진의 출처 펼침에 표시합니다. 서드파티 유료 사진 API나 생성 이미지로 실제 장소를 대체하지 않았습니다.

## 카드·탐색·준비 체크 보강 · 2026-10-18

테마 사이드바를 440px에서280px로 줄였습니다. 모서리·선택색·서체는 지도와 공유하고 목적에 맞게 폭을 달리합니다. 메뉴를 네 그룹으로 나누고 사진 카드에는 동일한 사진 높이·제목·요약·운영시간·휴무·출처·하단 행동 순서를 적용했습니다. 큰 화면도 최대3열이며 사진을 확보하지 못한 후보는 별도의 간결한 목록으로 표시합니다. 작은 사진을 위해6열로 좁히던 구성을 제거했습니다. 야경 사진은 실제 원본을 시각적으로 검토했습니다.

준비 체크는 우선 확인 3가지, 개인 진행률과 전체·미완료 필터, 그룹별 완료 수, 접힌 실행 안내, 기기 백업 관리로 구성합니다. Suica를 먼저 표시하고 환율은 접었습니다. 실제 예약·결제 확정과 개인 체크의 의미를 구분합니다. 세부 기준은 PREPARATION_REVIEW.md에 있습니다.

## 준비 체크의 반복 카드 제거 · 2026-10-18

사용자가 여전히 정형적인 생성형 화면처럼 보인다고 지적했다. 기존 세 칸 요약·01/02/03 번호·큰 완료 숫자·항목별 같은 안내 문구를 제거했다. 제목과 날짜, 작은 완료 수, 얇은 진행률 뒤에 실제 체크 목록이 바로 나온다. 항목마다 확인할 내용을 구체적인 한 줄로 쓰고 긴 안내는 우측 상세 동작으로 옮겼다. 예약 바로가기는PC 보조 열, 모바일에서는 체크 목록 뒤에 배치했다. 흰 목록 판과 기존 서비스의 색·서체를 유지하고 그림·강조색·장식용 통계를 추가하지 않았다.

수정 후 62개 테스트와 실제 Chrome 전체 QA 통과. 준비 체크의 필터·초점 이동·저장·부분 백업·잘못된 복원·완료 상태 및1440/768/390/320px 검사 통과, 페이지 예외 0건. PC·모바일 새 캡처를 직접 검토했다. 자동 검사 통과를 미적 선호 승인으로 보고하지 않는다.

## 테마 카드 밀도·사진 모션 조정

사진150px, 대표 썸네일96px로 줄이고 카드의 주소·이용 조건·검증 자료·출처를 방문 정보·출처 안에 모았습니다. 기본 이름순 목록에서는 사진이 없는 후보도 같은 순서를 유지하며, 사진 있는 순을 별도로 선택할 수 있습니다. 카드의 제목2줄·설명2줄·간단한 운영/휴무를 먼저 보이고 긴 원문은 펼쳐 읽습니다. 중요한 휴관·일반 비공개 조건은 기본 화면에 남깁니다. 빈 추가 사진 토글은 표시하지 않습니다.

1380px 이상에서3열, 좁은 화면은2열 또는1열입니다. 원본 사진의 크롭/전체 구도 전환은object-fit의 순간 변경을 제거하고280ms transform 보간으로 구현했습니다. 커서 위치에 따른 이동은 전체 사진이 프레임 안에 남는 여백 내로 제한합니다. 키보드 포커스도 전체 구도를 보이고 모션 줄이기 설정은 즉시 전환합니다. 클릭/터치의 원본 비율 확대 모달·촬영 범위·사용권은 유지합니다.

## 카드 사진·모션 재작업 · 2026-10-18
